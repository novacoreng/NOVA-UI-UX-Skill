# Release Checklist

- [ ] Update version in `skill.json`.
- [ ] Update plugin/marketplace metadata.
- [ ] Sync canonical source into CLI and Claude distribution.
- [ ] Run Python validation scripts.
- [ ] Run catalog/data-contract tests.
- [ ] Run relevance tests.
- [ ] Run stack smoke tests.
- [ ] Check for stale branding.
- [ ] Check package paths and platform templates.
- [ ] Verify README installation instructions.
- [ ] Verify no secrets or private files are included.
- [ ] Build the distributable archive.
- [ ] Record archive SHA-256 and file count.
- [ ] Create release notes.
