# Nova Master Build Workflow

## Phase 0 — Understand
1. Read PRD/TRD and existing design references.
2. Extract users, journeys, entities, permissions, routes, backend contracts and acceptance criteria.
3. Identify target platforms, devices, browsers, network assumptions and performance budget.

## Phase 1 — Design decision
1. Generate only visual directions supported by the product requirements.
2. If more than one is valid, ask the user to choose before locking the visual language.
3. Lock typography, color, spacing, components, motion, effects, density and responsive behavior.

## Phase 2 — Architecture
Create the route map, information architecture, component tree, state matrix, data-flow map and integration boundaries.

## Phase 3 — Build the foundations
Implement tokens, typography, theme, responsive primitives, accessibility primitives, navigation, forms, state handling and data-fetching patterns before decorative effects.

## Phase 4 — Product UI
Implement complete screens and flows with real loading, empty, error, offline, permission, validation, success and destructive states.

## Phase 5 — Advanced visuals
Only where approved: 3D/WebGL, liquid glass, shader gradients, scroll worlds, liquid identity, advanced notifications and cinematic motion. Every effect gets a fallback and budget.

## Phase 6 — Platform adaptation
Tune for desktop, tablet, mobile, native safe areas, keyboard, gestures, orientation, text scaling, SSR/SEO where applicable and device capabilities.

## Phase 7 — QA
Audit accessibility, responsive behavior, runtime errors, network behavior, visual consistency, performance, localization, security/privacy and critical user journeys.

## Phase 8 — Delivery
Record the final design direction, tokens, component inventory, backend assumptions, visual budgets, fallbacks, test results and remaining gaps.

## Non-negotiables
- No fake backend success.
- No blank screens for expected states.
- No inaccessible decorative effects.
- No uncontrolled heavy effects across every component.
- No hard-coded secrets.
- No silent visual redesign when a reference is locked.
- No production-ready claim without an audit.
