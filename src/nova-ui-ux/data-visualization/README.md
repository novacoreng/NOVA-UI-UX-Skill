# Nova Data Visualization System

## Supported patterns

- Line, area, bar, stacked, grouped and composed charts
- Pie/donut only when part-to-whole is genuinely useful
- Scatter, bubble, heatmap and distribution views
- KPI/stat cards with trend context
- Tables paired with charts for exact values
- Geographic maps and marker/clustering patterns
- Timelines and event histories

## Rules

Always provide labels, units, time ranges, legends and accessible summaries. Never communicate meaning by color alone. Handle loading, empty, partial, error and stale states. Support responsive resizing, long labels, dense datasets, keyboard alternatives where applicable, reduced motion and data export when product requirements call for it. Prefer progressive detail: summary first, exploration second, raw data when precision matters.
