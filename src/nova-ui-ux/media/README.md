# Nova Media System

## Image strategy

Use meaningful focal points, responsive source selection, appropriate aspect-ratio boxes, lazy loading below the fold, decoding priorities and explicit dimensions to prevent layout shift.

## Video

Use poster frames, muted autoplay only where appropriate, pause controls, reduced-motion alternatives, responsive source selection, captions/transcripts and failure fallbacks.

## Audio

Never autoplay unexpectedly. Provide clear play/pause state, progress, duration, volume and accessible labels.

## Uploads

Define accepted types, size limits, progress, cancellation, retry, validation, preview, removal, upload failure and resumability where needed.

## Content resilience

Test missing media, slow media, broken URLs, extreme aspect ratios, long captions and user-generated content.
