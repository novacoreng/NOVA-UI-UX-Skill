# Nova SEO and Content System

For web builds define document title, description, canonical URL, robots behavior, Open Graph, social preview image, favicon/app icons, structured data where appropriate, language/locale, viewport and theme metadata.

Content architecture must support headings, semantic landmarks, link purpose, crawlable navigation, meaningful URLs and share previews. Avoid using visual text inside images when semantic HTML can express it. Treat generated/user content as untrusted and escape/sanitize appropriately.
