# Nova Component Primitive System

A framework-neutral inventory and behavior contract for production UI primitives.

## Primitive families

- Actions: button, icon button, split button, floating action, command action
- Inputs: text, search, password, number, select, combobox, checkbox, radio, switch, slider, date/time, file, OTP
- Navigation: tabs, segmented control, breadcrumbs, pagination, stepper, sidebar, bottom navigation, command palette
- Surfaces: card, sheet, drawer, modal, popover, tooltip, menu, context menu, toast, banner
- Data: table, list, grid, tree, timeline, calendar, filters, sort controls
- Feedback: progress, skeleton, spinner, empty state, alert, validation, status
- Content: avatar, badge, chip, tag, media, carousel, accordion, disclosure

Every primitive must define anatomy, states, keyboard behavior, focus behavior, responsive behavior, accessibility name/description, loading/error/disabled variants, theming tokens and content overflow rules.
