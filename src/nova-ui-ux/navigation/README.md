# Nova Navigation System

Model navigation around information architecture and task frequency.

## Patterns

- Top navigation for broad product areas
- Sidebar for persistent multi-section workspaces
- Bottom navigation for high-frequency mobile destinations
- Tabs for peer views within one context
- Breadcrumbs for hierarchical depth
- Stepper for finite multi-step tasks
- Command palette for power-user navigation/actions
- Context menus for local actions
- Search/discovery navigation for large content systems

Define current/hover/focus/pressed/disabled states, deep-link behavior, back behavior, unsaved-change handling, responsive transformation, keyboard traversal and screen-reader announcements.
