# Nova UI/UX Testing System

## Test layers

1. Component behavior and state tests
2. Accessibility tests
3. Responsive viewport tests
4. Interaction/gesture tests
5. Route/navigation tests
6. API and error-state tests
7. Visual regression tests
8. End-to-end critical-flow tests
9. Performance tests
10. Device/browser compatibility tests

Critical flows should verify loading, success, validation, error, empty, offline/degraded and permission states. Visual checks should cover representative breakpoints, theme variants and reduced motion. Browser automation should check console errors, failed requests, layout overflow and primary interactions.
