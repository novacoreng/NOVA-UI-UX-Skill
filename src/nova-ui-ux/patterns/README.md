# Nova Product Pattern Catalog

## Product patterns

- Authentication and onboarding
- Profiles and account settings
- Dashboards and workspaces
- Search and filtering
- Commerce and checkout
- Payments and wallets
- Messaging and chat
- Social feeds and reactions
- Campaign/fundraising flows
- Notifications and activity centers
- File/media management
- Maps and location flows
- Scheduling and calendars
- Admin/moderation
- Permissions and role management
- Multi-tenant organization flows
- Subscription/billing management

For every pattern define happy path, alternate path, failure path, permissions, persistence, navigation, responsive transformation, accessibility and recovery behavior.
